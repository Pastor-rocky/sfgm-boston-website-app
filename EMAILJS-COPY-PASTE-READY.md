# 📋 Copy & Paste EmailJS Environment Variables for Render

## 🚀 Instructions

1. Go to Render Dashboard → Your Service → **Environment** tab
2. Click **"Add Environment Variable"**
3. Copy the **NAME** (first line) → Paste in "Key" field
4. Copy the **VALUE** (second line) → Paste in "Value" field
5. Click **"Save Changes"**
6. Repeat for all 9 variables below
