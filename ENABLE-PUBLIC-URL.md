# Enable Public Development URL

## The Issue

You can see the Public Development URL, but it needs to be **ENABLED** to work.

## Steps to Enable

1. **In the Settings page you're on:**
   - Look at the "Public Development URL" section
   - There should be a **toggle switch** or **"Enable"** button
   - Turn it **ON** or click **"Enable"**

2. **If you don't see a toggle:**
   - The URL might already be enabled
   - But files still need to be uploaded

## Check Files Are Uploaded

1. **Go back to the main bucket view:**
   - Click on your bucket name `sfgmboston` in the sidebar
   - Or click "Overview" under R2

2. **You should see:**
   - A list of files
   - Or an empty bucket with "Upload" button

3. **If bucket is empty:**
   - Click "Upload" or drag & drop
   - Upload all 10 `acts-in-action-cp*.mp3` files

## Quick Checklist

- [ ] Public Development URL is ENABLED (toggle ON)
- [ ] Files are uploaded to the bucket
- [ ] File names match exactly: `acts-in-action-cp1.mp3`, etc.
